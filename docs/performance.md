# 性能文档

> 验证日期：2026-09-25

## 测量设备与方法

- **设备**：MacBook Pro M3 Pro, 18 GB RAM
- **显示器**：Dell S3225QS 6K (6016x3384) @ 120Hz
- **工具**：Xcode Instruments（Time Profiler, Allocations, Energy Log, Metal System Trace）

## 性能模式实现

| 模式 | 渲染比例 | 帧率上限 | 说明 |
|------|---------|---------|------|
| 自动 | 0.5 | 60 | 根据窗口可见性/低电量/热状态调整 |
| 节能 | 0.3 | 30 | 低分辨率背景，保留文字清晰度 |
| 高质量 | 0.6 | 60 | 前台稳定 60fps |
| 静态 | 0 | 0 | 停止 Metal 绘制，静态封面配色 |

## 已知限制

1. **频谱**：当前使用环境动画，未使用真实 PCM。真实频谱需要本地文件或预下载方案。
2. **4K/6K 屏幕**：全屏背景不默认使用满分辨率，通过 `renderScale` 降低渲染比例再合成。
3. **高刷新率**：120Hz 屏幕可选择更高上限，但不把 120fps 当默认耗电目标。

## 后续测量计划

4. 使用 Metal System Trace 验证 GPU 利用率
