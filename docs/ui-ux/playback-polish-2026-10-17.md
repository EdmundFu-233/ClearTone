# Apple 播放体验优化与验收 · 2026-10-17

本轮仅涉及 macOS、iOS/iPadOS 及共享 Swift 逻辑。保留工作区已有改动，没有修改 Windows，也没有提交或发布远程版本。

## 体验改动

- macOS 播放页拆分封面、控制区和歌词阅读区；封面同时受窗口宽、高约束，较短窗口可滚动；补充加载、缓冲、失败重试状态。
- 从 16×16 的封面采样提取背景色，限制背景亮度；Metal 在已有绘制循环中平滑过渡颜色，不创建额外动画计时器。
- 进度和歌词只更新各自的局部视图；移除桌面歌词页额外的 10Hz 轮询，使用播放器已有的进度发布。
- 歌词改为逐行按钮，支持键盘聚焦及独立的辅助功能描述。逐字歌词使用可换行的富文本，避免单行 HStack 溢出。
- macOS 滚轮/触控板输入会暂停歌词跟随；“回到当前歌词”立即定位。切歌恢复跟随，减少动态效果设置关闭非必要运动。
- iPhone 竖屏封面高度给长歌名和底部操作留出空间；横屏采用双栏和更紧凑间距。封面/歌词切换保持控制区位置。
- iPad 使用完整的播放界面，竖屏纵向排列，横屏双栏，避免默认小弹窗阻止宽屏布局。iPhone 保留原生抽屉。

## 内存与渲染约束

- macOS 与 iOS 共用 ImageIO 后台缩略图解码，按显示像素尺寸解码并区分缓存键，避免先展开全尺寸图片。
- 封面 HTTP 内存缓存预算统一为 8 MiB；解码图片缓存保持 32 MiB 的成本预算。NSCache 成本预算不是进程内存硬上限。
- 环境背景自动档按 30 FPS、0.5 渲染比例运行；视图销毁时暂停并释放绘制资源。减少动态效果模式使用静态背景。
- 修复 FFT 缓冲指针的生命周期，使 Accelerate 调用始终位于有效缓冲区作用域内。

## 本轮修复的状态问题

1. 收藏列表的迟到读取可能覆盖已经发起或已经成功的收藏。读取携带写入版本和请求令牌；版本过期的响应不再覆盖本地状态。收藏写入期间不启动新的列表读取。
2. 退出并登录另一个账号后，旧账号收藏请求失败可能污染新账号的红心、错误提示和冷却状态。写操作完成和回滚均核对账号代次。
3. 歌曲元数据更新不再无条件清空歌词；歌词加载身份使用来源和歌曲 ID。
4. 播放时间格式化和进度范围拒绝 NaN、Infinity、负数及无法安全转成整数的数值。
