# 澄音 UI/UX 与 Liquid Glass

2026-09-25。本轮沿用现有珊瑚红与暖灰配色，调整原生 SwiftUI 界面。

## 已完成

- macOS 26+：搜索框、悬浮播放栏使用原生 `glassEffect(.regular, in:)`。macOS 14–15 使用 regularMaterial；开启减少透明度时使用实色面板。歌曲内容不套用玻璃。
- 播放栏移到导航与队列外，横跨窗口底部；取消原来的 280 + 400 + 280 固定宽度。
- 侧栏增加品牌标识、探索/资料库分组和设置入口；移除无行为的前进/后退按钮及重复工具栏标题。
- 喜欢的音乐增加统一页头、歌曲数量与播放全部；歌曲行显示明确播放入口及当前曲目底色。
- 顶部搜索回车将关键词传入搜索页；空结果明确提示更换关键词或类型。
- 推荐歌单卡片接入详情导航，改为可键盘访问的 Button；移除尚未实现的喜欢按钮。
- 播放进度改为原生 Slider，可使用辅助功能操作；缓冲秒数在帮助文本显示，取消原先仅支持指针拖动的自绘缓冲轨道。
