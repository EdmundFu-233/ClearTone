# iOS UI / UX 优化与验收

2026-09-30。在现有 SwiftUI iOS target 上直接实现；沿用靛蓝色、系统字体、语义背景色、SF Symbols 与原生导航。保留工作区已有 iOS 功能与免费账号签名约束。

## 体验改动

- 发现：文字列表改为自适应封面网格；压缩介绍卡，突出精选歌单和每日推荐入口。大字体改为纵向列表。下拉刷新保留已有内容，失败提供重试，账号或请求切换后丢弃旧响应。
- 底部播放条：置于各标签页面的底部安全区、标签栏上方。歌曲入口、暂停/继续和下一首均可直接操作；订阅播放器时间流展示进度，区分加载、缓冲与失败。减少透明度设置使用实色背景。
- 搜索：常驻搜索框、最近搜索、删除/清除历史及节流搜索建议；复用已测试的 SearchSession 和 SearchAssistStore。新搜索加载或失败时不显示旧结果。
- 资料库：账号介绍、喜欢/最近/本地音乐入口加入语义图标与说明；未登录时喜欢入口引导登录。创建歌单不允许空白名称。
- 详情与歌曲列表：播放全部使用突出按钮，长简介默认折叠，大字体详情头纵向排列。
- 播放页：封面随宽度缩放，五个主要控制均匀分布；喜欢操作补登录入口，播放失败可重试。歌词具有加载/空态/重试及当前行自动定位，遵循减少动态效果设置。倍速和睡眠定时收进顶部菜单；队列保留排序、移除和清空确认。
- 设置：说明移到分组 footer，减少设置行噪声。
