# 澄音 ClearTone 26.2（Windows）

- Windows 以 portable ZIP 发布，解压后直接运行 `ClearTone.exe`。
- 设置、登录凭据、播放队列、历史、音频和封面缓存、日志、辅助进程设备 ID 统一保存在 EXE 旁的 `data` 文件夹。
- 增加 EXE 图标，并统一窗口、托盘与开始菜单快捷方式图标。
- 压缩包包含 `Add-to-Start-Menu.bat` 和 `Remove-from-Start-Menu.bat`，无需管理员权限即可添加或删除当前用户的开始菜单快捷方式。
- 开始菜单快捷方式支持中文路径、空格和特殊字符目录。
- 每日推荐上方增加「以列表呈现」按钮，使用与歌单相同的歌曲列表，可切回横排卡片。
- 播放底栏和正在播放页增加「添加到歌单」按钮，支持歌单选择、失败重试与登录状态检查。
- 清理旧版工程的遗留脚本、迁移说明与对照注释，Windows 开发约定统一为 Qt Widgets、C++20 与 Rust。

## 使用与更新

完整解压对应架构的 ZIP 后运行。更新前先退出应用，覆盖程序文件并保留 `data` 文件夹。
移动应用目录后重新运行 `Add-to-Start-Menu.bat`，即可更新快捷方式路径。

旧版 AppData 数据不会自动迁入。凭据仍使用 Windows DPAPI 加密，换电脑或 Windows 用户后需要重新登录。

本次为指定版本号的 Windows 26.2 发布，保留现有 27.x Release 的最新版标记。
