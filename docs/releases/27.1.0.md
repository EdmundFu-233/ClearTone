# 澄音 ClearTone 27.1.0

macOS / iOS 版本号统一为 27.1.0。本次新增 iOS 桌面快捷入口 Widget。

## 下载

- **macOS**：`ClearTone-v27.1.0.dmg`，拖入「应用程序」即可。开发证书签名、未公证，首次打开需右键 →「打开」。
- **iOS 17+**：`ClearTone-v27.1.0-ios-unsigned.ipa` 为未签名设备包，需用侧载工具（AltStore / Sideloadly 等）以自有 Apple ID 重签后安装；不含 Node，原生直连网易云。
- **Windows x64 / ARM64**：`ClearTone-win-x64.zip` / `ClearTone-win-arm64.zip`，由 CI 从同一提交构建。Windows 沿用独立的 26.x 版本线，功能与 26.2 一致（含其后的 Unicode 路径与开始菜单修复）。

## 更新内容

- **iOS 桌面 Widget**：新增小 / 中 / 大三档快捷入口，一键打开发现、搜索、资料库与正在播放；点击正在播放会直接弹出播放器。
- **不给免费账号添门槛**：Widget 扩展**不建 App Group**、不申请任何额外 entitlement，仍然可以用免费 Personal Team 签真机。代价是扩展读不到主 App 的账号与播放数据，因此只做快捷入口，不显示歌曲信息。
- **Deep link**：新增 `cleartone://` scheme（`discover` / `search` / `library` / `now-playing` / `settings`），Widget 与主 App 共用同一份 `ClearToneDeepLink` 定义，避免两边拼写漂移。
- **构建与部署**：iOS App 与 Widget 的 bundle ID 统一由 `CT_APP_BUNDLE_ID` 推导；`build-ios.sh` 会校验只嵌入 `ClearToneWidget.appex`，`deploy-ios.sh` 会分别检查宿主与扩展的签名 entitlement。

## 测试

610 项离线测试全部通过。新增 `ClearToneDeepLinkTests`，覆盖每个入口的 URL 往返、`cleartone:///x` 形式、外部 scheme 与未知目标的拒绝。

## 已知限制

Widget 不显示正在播放、最近播放或账号内容。如果以后要显示这些数据，需要付费开发者账号开启 App Group，并同步调整本仓库「iOS 只用免费能力」的构建校验。
